01

Conectar

Funciona no Claude da web, no Desktop, no celular e no Claude Code. Conectou uma vez na conta, vale em todos os dispositivos dela.

AI

claude.ai · Desktop · mobile

  1. Abra Settings → Connectors → Add custom connector.
  2. Cole {{ url_conector }} e deixe OAuth Client ID/Secret em branco.
  3. Clique em Connect: entre com o e-mail e a senha do Voyager.
  4. Confira o destino e clique em Autorizar. Pronto.
>_

Claude Code

  1. Adicione o servidor no terminal:
    claude mcp add --transport http voyager {{ url_conector }}
  2. No Claude Code, rode /mcp, escolha voyager → Authenticate e faça o mesmo login no navegador.

Quem pode usar

Quem tem conta no Voyager e foi liberado para o conector por um administrador. Sem a liberação, a tela de login avisa — nada é consultado.

Outros clientes MCP

Cursor, Gemini CLI, API da OpenAI e integrações próprias usam um token fixo. As receitas estão em /dashboard/mcp.
