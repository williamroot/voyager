MCP · Configuração

Como conectar o Voyager a LLMs e agentes de IA (Claude, ChatGPT, Gemini, Cursor) via Model Context Protocol.

Endpoint

URL base: https://voyager.was.dev.br/mcp
Descriptor: https://voyager.was.dev.br/mcp/.well-known/mcp.json
Transport: Streamable HTTP (JSON-RPC 2.0) · auth OAuth 2.1 ou token fixo

◉ Claude — claude.ai, Desktop, mobile e Claude Code

O login é o do próprio Voyager (o mesmo e-mail e senha deste dashboard), por OAuth — não há token pra copiar. Além da conta, o acesso precisa estar liberado por um superusuário em Django admin → Acessos ao MCP.

{% if tem_acesso %}● Sua conta está liberada para o conector. {% else %}● Sua conta ainda NÃO está liberada para o conector — peça a um superusuário.{% endif %}

claude.ai / Desktop / mobile

  1. Abra Settings → Connectors → Add custom connector
  2. URL: https://voyager.was.dev.br/mcp — deixe OAuth Client ID/Secret em branco
  3. Clique em Connect: abre o login do Voyager e depois a tela Autorizar acesso
  4. Pronto — o conector vale para o Claude em todos os dispositivos da sua conta

Claude Code (CLI)

claude mcp add --transport http voyager https://voyager.was.dev.br/mcp

Depois rode /mcp no Claude Code e escolha Authenticate: o navegador abre o mesmo login.

Token fixo (outros clientes e integrações)

Clientes que não falam OAuth usam um token MCP (UUID) de um ApiClient. Gere via command (gira o token):

python manage.py gerar_mcp_token <nome_cliente>

Cole o token acima e os exemplos abaixo serão preenchidos automaticamente. Claude Code com token fixo: claude mcp add --transport http voyager https://voyager.was.dev.br/mcp --header "Authorization: Bearer SEU-TOKEN"

◉ ChatGPT (developer mode)

  1. Abra Settings → Connectors → Create
  2. URL: https://voyager.was.dev.br/mcp/
  3. Auth: header Authorization: Bearer <token>

◉ Google Gemini (AI Studio)

  1. No Google AI Studio, abra Settings → Tools → MCP Servers
  2. Add server: URL https://voyager.was.dev.br/mcp/
  3. Header: Authorization: Bearer <token>
  4. O Gemini terá acesso às tools e poderá buscar processos, ver partes, jurimetria, etc.

Alternativa via SDK Python: use a lib google-genai com tools=mcp.Server(url=..., headers={"Authorization": "Bearer ..."}).

◉ Cursor

  1. Abra Settings → Models → MCP
  2. Add MCP Server: URL https://voyager.was.dev.br/mcp/
  3. Header: Authorization: Bearer <token>

Ou edite ~/.cursor/mcp.json diretamente:

{
  "mcpServers": {
    "voyager": {
      "url": "https://voyager.was.dev.br/mcp",
      "headers": { "Authorization": "Bearer SEU-TOKEN" }
    }
  }
}

◉ Clientes customizados (HTTP/JSON-RPC)

O MCP server usa JSON-RPC 2.0 sobre HTTP. Exemplos com curl:

Listar tools
curl -X POST https://voyager.was.dev.br/mcp/messages \
  -H "Authorization: Bearer SEU-TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"method":"tools/list","id":1,"params":{}}'
Buscar diários
curl -X POST https://voyager.was.dev.br/mcp/messages \
  -H "Authorization: Bearer SEU-TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"method":"tools/call","id":2,"params":{"name":"buscar_diarios","arguments":{"query":"precatório","size":5}}}'
Dossiê de processo
curl -X POST https://voyager.was.dev.br/mcp/messages \
  -H "Authorization: Bearer SEU-TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"method":"tools/call","id":3,"params":{"name":"contexto_processo","arguments":{"cnj":"1097648-06.2025.4.01.3400"}}}'

Tools disponíveis (17)

buscar_diarios — busca textual em diários oficiais (ES)
get_documento — detalhe de publicação por ID
get_processo — dados de um processo por CNJ
list_movimentacoes — movimentações de um processo
get_partes — partes (polo ativo/passivo/outros)
listar_fontes — diários/tribunais cobertos
status_cobertura — cobertura por área
buscar_entidades — busca por nome/doc/OAB
buscar_valores — busca por faixa de valor da causa
jurimetria — estatísticas (volume/valores/classificação/andamentos)
contexto_processo — dossiê completo (partes+movs+timeline)
buscar_por_parte — busca por nome de parte + estatísticas
monitorar_termo — cria monitoramento push (webhook)
monitorar_processo — cria monitoramento de processo
listar_detections — detecções recentes
get_pdf — URL do PDF armazenado
classificacao_lead — score de ML (gated)

Resources

voyager://processo/{cnj} — dados de um processo
voyager://movimentacao/{id} — detalhe de uma publicação
voyager://contexto/{cnj} — dossiê completo enriquecido
voyager://fontes — lista de fontes/diários
