Conectou uma vez, vale em todos os dispositivos da sua conta do Claude. Para desconectar: Settings → Connectors → Voyager → Disconnect.

{# Claude Code #}
1 · Adicione o servidor
claude mcp add --transport http voyager {{ url_conector }}
2 · Autentique

Dentro do Claude Code, rode /mcp, escolha voyager → Authenticate e faça o login do Voyager no navegador que abrir. Para valer em todos os projetos, acrescente --scope user ao comando.

{# Outros #}

Clientes que não fazem o login OAuth do Claude usam um token fixo (UUID) de um ApiClient. Peça a um administrador — ele roda python manage.py gerar_mcp_token <nome> (cada execução gira o token e o anterior morre).

{
  "mcpServers": {
    "voyager": {

  }
}

  }
}

HTTP direto (JSON-RPC 2.0)
curl -s {{ url_conector }} \
  -H "Authorization: Bearer SEU-TOKEN" \
  -H "Content-Type: application/json" \

       "params":{"name":"visao_geral","arguments":{}}}'
